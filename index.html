How to Play

Multiplayer Pictionary is a fun drawing and guessing game you can play with friends! Here's how it works:

  • Create a room and share the room code with your friends.
  • Join a room using the room code shared by the host.
  • Wait in the lobby until the host starts the game.
  • Take turns drawing and guessing the given words. Points are awarded for correct guesses!
